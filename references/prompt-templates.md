# LLM Prompt 模板参考（references/prompt-templates.md）

> 集中维护 LLM 调用所需的 Prompt。落地版见 `templates/summary_prompt.txt`；本文件为说明与变体管理。

## 1. 视频内容总结（≤100 字）

```
请用 100 字以内概括该视频的核心内容，要求涵盖主题、核心观点和关键结论。
仅输出概括文本，不要分点、不要解释。
```

## 2. 内容结构化小结（PREP 法则 + 金字塔原理）

- PREP = Point（观点）→ Reason（理由）→ Example（案例）→ Point（重申观点）。
- 金字塔原理：结论先行，上层统整下层，下层支撑上层。

结构化输出模板（由 `scripts/summarize.py` 拼装）：

```
### 核心观点
[一句话结论]
#### 论据1：[分论点]
- 支撑内容/案例
#### 论据2：[分论点]
- 支撑内容/案例
### 结论重申
[回扣核心观点]
```

## 3. 文字稿分段整理

- 将 ASR 原始文字稿按语义段落整理。
- **关键约束**：内容不可缺损、不可删减，仅做分段与标点优化。
- 每段前可加小标题概括该段要点（可选增强）。
- 若提供时间戳，在段落标注对应视频时间戳（如 `[05:30]`）便于回溯。

## 4. 标签规范化

- 自动统一标签格式：将"人工智能"统一为 `#人工智能`，去除平台特有前缀。
- 最终保留 2–5 个标签；优先保留平台自带 tag，不足则用 AI 推断补充。

## 5. 调用约束

- 使用 JSON 模式（若模型支持）保证字段稳定；或要求严格按模板输出。
- `temperature` 建议 0.3（见 `config.example.yaml` 的 `llm.temperature`），降低随机性。
- 失败降级：LLM 不可用时仅保留文字稿与基础模板（见 `ERR_SUMMARY_FAILED`）。
